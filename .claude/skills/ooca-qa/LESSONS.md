# QA Lessons — บทเรียนจากจุดที่เคยผิด

> QA ต้องอ่านไฟล์นี้ก่อนตรวจงานทุกครั้ง และตรวจข้อเหล่านี้ก่อน
> ผู้บันทึก: Knowledge agent (จาก QA Report ของ skill `ooca-qa`)
> อัปเดตล่าสุด: 2026-10-25

## รูปแบบการบันทึก

```markdown
### <หมวด: Figma / โค้ด UI / Mooca / ข้อความ UI> — <หัวข้อสั้นๆ>
- **ผิดอย่างไร:** <ค่าที่เคยใช้ผิด>
- **ที่ถูก:** <ค่าที่ถูก> (อ้างอิง: <ไฟล์ § หัวข้อ>)
- **วิธีกันผิดซ้ำ:** <สิ่งที่ต้องเช็กทุกครั้ง>
- **พบครั้งแรก:** YYYY-MM-DD · **จำนวนครั้ง:** N
```

ถ้าเป็นจุดผิดเดิม ให้เพิ่มจำนวนครั้งในหัวข้อเดิม ไม่ต้องสร้างหัวข้อใหม่
